# ✨ Styleva

### Shop. Try. Glow. Love.

**Styleva** is a personal frontend project exploring the future of online fashion and beauty shopping.

The platform combines **fashion ecommerce, beauty shopping, virtual clothing try-on, and virtual makeup experiences** into one modern shopping experience. The goal is to let users discover products, experiment with their style, and make more confident purchasing decisions before buying.

> 🛍️ Shop fashion & beauty
> 👗 Virtually try on clothes
> 💄 Experiment with makeup virtually
> ✨ Discover your personal style

---

## 🌸 About The Project

Styleva was created as a personal project to explore how **modern UI/UX design, ecommerce, and virtual experiences** can come together in a single platform.

Instead of simply displaying products, Styleva is designed around the idea of:

**"Try it before you buy it."**

Users can browse fashion and beauty products while interacting with virtual try-on and virtual makeup experiences.

This project is currently a **frontend prototype**. The virtual try-on and makeup features are simulated on the frontend and are structured so that real AI/AR technology could be integrated in the future.

## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/styleva.git
```

### Navigate into the project

```bash
cd styleva
```

### Run the project

Because Styleva is a frontend project, you can run it using a local development server.

For example, with VS Code, install the **Live Server** extension and open:

```text
index.html
```

Alternatively, use any local development server of your choice.
